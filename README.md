# صياد الأسعار 💰🔍

يبحث عن المنتج في 12 متجر سعودي **بنفس اللحظة** ويرتّب النتائج من الأرخص.

كل محوّل تم فحصه على الموقع الحقيقي (2026-10-14):
النهدي، المتحدة، وايتس، وافي ترند، آي براند، بندة، الدانوب، كارفور، لولو، التميمي، أمازون، نون.
موقوف: الدواء (حماية Cloudflare)، مخازن العناية (ما لهم متجر إلكتروني معروف).

## الملفات
| الملف | وظيفته |
|---|---|
| `server.js` | السيرفر: يستقبل البحث ويرسله لكل المتاجر بالتوازي |
| `stores.js` | قائمة المتاجر — **لإضافة متجر تضيف سطر هنا فقط** |
| `adapters/salla.js` | محوّل متاجر سلة (وافي ترند، آي براند، وأي متجر سلة) |
| `adapters/amazon.js` | محوّل أمازون |
| `adapters/generic.js` | محوّل عام لباقي المتاجر |
| `public/index.html` | واجهة التطبيق |
| `test-store.js` | تجربة متجر واحد من الطرفية |

## الرفع على Render (مجاناً)
1. ارفع المجلد كامل على GitHub كمستودع جديد اسمه `sayyad-alasaar`.
2. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
3. **New → Web Service** واختر المستودع.
4. Render يقرأ الإعدادات تلقائياً من `render.yaml`، اضغط **Deploy**.
5. بعد دقيقتين يعطيك رابط مثل `https://sayyad-alasaar.onrender.com` — افتحه وجرّب.

> الخطة المجانية تنام بعد 15 دقيقة بدون استخدام، فأول بحث بعدها ياخذ ~30 ثانية.

## تشغيل على جهازك
```bash
npm install
npm start          # يفتح على http://localhost:3000
node test-store.js all "سيريلاك"     # يجرب كل المتاجر
node test-store.js ibrand "بانادول"  # يجرب متجر واحد
```

## إضافة متجر سلة جديد
```js
{ id: 'mystore', name: 'اسم المتجر', group: 'صيدليات', type: 'salla', color: '#123456',
  base: 'https://mystore.com' },
```

## لما متجر يطلع ❌
أرسل لي اسم المتجر ورسالة الخطأ من أسفل الصفحة (أو من `test-store.js`) وأعدّل محوّله.
